▼ ELI5 — tl;dr
💬 comment
💡 Plain English
When a window opens on the desktop, its glass tube fires up the way a Terminal Delight pane does: the phosphor floods in, collapses to a scan line, pinches to a star, and the window emerges from behind the flash. When a window closes, the same arc runs from its midpoint — the screen closes to a line, the line dies to a star, and the vacated space shows through before the last light is gone. 300 ms, one knob, off by default. Done looks like: two photographs of it happening on the live desktop, and a probe suite that proves the trigger mechanism before any of it is built.
💬 comment
The mechanism in one breath
The watch already rebuilds and hot-swaps the screen shader on every window event, and Hyprland restarts a screen shader’s time uniform at zero on every apply (verified in the v0.56.2 source, the exact build installed). So a swap is a trigger: bake the dying or newborn rect into the shader as constants, swap, and a one-shot animation plays from t=0. The effect itself never needs the window’s pixels — Terminal Delight’s own ignition is emissive gradients over a dark ground, which a fragment shader reproduces from a rect and a clock. Full feasibility argument with source citations: reports/2026-09-05-ignition-port-feasibility.html.
▼ What ships
💬 comment
The effect
Ignition on openwindow, shutdown on closewindow, for every window that wears a curved tube. Terminal Delight windows are exempt by construction — they play their own per-pane ignition, and their tubes carry curvature 0, which is the gate.
💬 comment
The knob
One service-panel dial, IGNITION, 0..1. Ships at 0.00 — the template in git renders byte-identical to today, honouring the SHIPPED-AT-ZERO doctrine. Any value above zero enables both halves and scales the flash brightness; 1.0 is Terminal Delight’s exact glow curve. crt set IGNITION 1 works with no CLI changes, because service knobs resolve by constant name.
💬 comment
The probes
Three live-desktop probes: probe-clock-reset (the falsifier — built first, everything stops if it fails), probe-fx-freeze (holds the arc at any instant for a photograph, mirroring TD_IGNITION_FREEZE), and probe-fx-latency (the event-to-flash number that settles the one open taste question).

Source of truth is terminal-delight/app/src/crt.rs — the constants, the three movements, the easing, and the shutdown remap are ported as numbers, not as impressions. The Rust stays authoritative; a parity test pins the GLSL constants against this table.

💬 comment// TD's ignition(t), crt.rs:415 — per pixel, at warped-local w.
// Returns flash brightness (pre-IGNITION scale); ground = dark-face opacity.
float fx_pattern(vec2 w, float t, out float ground) {
    float f = 0.0;
    ground  = 1.0;
    if (t < FX_BLOOM_END) {                    // Bloom: ease-OUT flood from both edges
        float p   = t / FX_BLOOM_END;
        float e   = 1.0 - (1.0 - p) * (1.0 - p);
        float lit = 0.5 * e;
        float g   = 0.35 + 0.45 * e;
        if (w.y < lit)            f = g * (1.0 - w.y / max(lit, 1e-4));
        else if (w.y > 1.0 - lit) f = g * (1.0 - (1.0 - w.y) / max(lit, 1e-4));
    } else if (t < FX_COLLAPSE_END) {          // Collapse: ease-IN to a scan line
        float p  = (t - FX_BLOOM_END) / (FX_COLLAPSE_END - FX_BLOOM_END);
        float e  = p * p;
        float hh = 0.5 * (1.0 - e);
        float g  = 0.8 + 0.2 * e;
        float d  = abs(w.y - 0.5);
        if (d < hh) f = g * (1.0 - d / max(hh, 1e-4));
    } else {                                   // Pinch: four-pointed star, ground opens
        float p  = (t - FX_COLLAPSE_END) / (1.0 - FX_COLLAPSE_END);
        float e  = p * p;
        float wd = 0.5 * (1.0 - e);            // streak half-extent (width fraction)
        float sp = 0.26 * (1.0 - e);           // spike half-length (height fraction)
        float g  = 1.0 - e;                    // hot for the first half, dead at the end
        ground   = 1.0 - p;                    // linear reveal underneath
        float dx = abs(w.x - 0.5), dy = abs(w.y - 0.5);
        float fh = (dy < FX_ARM * 0.5 && dx < wd) ? g * (1.0 - dx / max(wd, 1e-4)) : 0.0;
        float fv = (dx < FX_ARM * 0.5 && dy < sp) ? g * (1.0 - dy / max(sp, 1e-4)) : 0.0;
        f = max(fh, fv);
    }
    return f;
}
💬 comment
Layering, exactly as the terminal does it
The flash composites after the base colour is sampled and before the scanline, tracking, vignette and grade stages — TD’s words: “above the grid and below the glass”. The scanlines and curvature in the result are not drawn by the effect; they are what the glass does to whatever it is shown. The flash stays white, as in TD — the grade and phosphor stages tint it downstream.

💬 comment
Why the swap is the trigger
Hyprland v0.56.2, src/render/OpenGL.cpp: applying a screen shader with a time uniform records setInitialTime(globalTimer), and every frame feeds the shader globalTimer − initialTime. The two-slot swap always forces a fresh apply (Hyprland refuses to recompile a path already in use, which is why the slots alternate), so every swap is a clock reset. This is an implementation detail, not a documented contract — which is why the falsifier probe is the first ticket and re-runs after any compositor upgrade.
▼ The watch state machine
💬 commentFX_S, FX_PAD, FX_LEAD, FX_MAX = 0.30, 0.05, 0.03, 8

fx        = {}   # addr -> (kind, mon, rect, curv, t0_monotonic)
addr_rows = {}   # addr -> row, from the LAST snapshot (the only place a
                 #          closed window's rect still exists)

def refresh(why, data=""):
    st = load()
    block, rows = td_tubes_snapshot(st)     # emit_block + capped json, one call
    if block is None: return
    enabled = ignition_level(st) > 0.0 and rows_carry_addr(rows)

    if enabled and why == "closewindow":
        row = addr_rows.get(norm_addr(data))
        if row and eligible(row, st):
            fx[norm_addr(data)] = Fx(SHUTDOWN, row, now())
    if enabled and why == "openwindow":
        addr = norm_addr(data.split(",", 1)[0])
        row  = index_by_addr(rows).get(addr)
        if row and eligible(row, st):
            fx[addr] = Fx(IGNITE, row, now())

    drop entries older than FX_S + FX_PAD; keep newest FX_MAX
    addr_rows = index_by_addr(rows)

    key, sig = block_key(block), fx_sig(fx)
    if key == last_key and sig == last_sig:
        return                              # nothing worth a recompile
    last_key, last_sig = key, sig
    write_tubes(block)
    write_fx(fx)                            # FX_START = −(now − t0 + FX_LEAD)
    apply(st)

# The blocking recv loop becomes a selectors loop so an expiry can fire
# with no event arriving:
#   timeout = min(t0) + FX_S + FX_PAD − now   (None when fx is empty)
#   on timeout: refresh("fx-expiry")          — prunes, swaps steady back in
💬 comment
The rule that prevents an infinite rebuild loop
fx_sig hashes (addr, kind, mon, rect, t0) and never the baked FX_START offsets. Offsets are recomputed at every bake, so including them makes every bake differ from the last and the watch rebuilds forever. The invariant that makes offsets correct anyway: FX_START constants are relative to the live apply, and every actual swap recomputes them — when no swap happens, the live constants stay right because the live clock kept running.
💬 comment
Who gets a flash
eligible(row): curvature above zero (flat surfaces and layers are not pretending to be CRTs — TD’s own rule; this also exempts Terminal Delight windows, which the geometry marks curv 0 and which play their own per-pane ignition), class not in the passthrough list (those pixels return early in the shader and a flash there could not draw), and — when quietUnfocused holds — the window’s monitor is the focused one, because a monitor that is not being rendered would freeze the flash mid-arc as a stranded artifact, exactly the reason TUBE_QUIET exists.
💬 comment
Identity is the window address, never the rect
Diffing rect lists misfires: closing one tiled window moves every sibling, and each moved rect would read as a death plus a birth — the whole workspace would flash on every retile. The socket2 events carry the window address (closewindow>>3f2a…), so the fx table is keyed by address and rects are looked up in the address map. That is what the one-line upstream change buys: tubes_json rows gain addr, and the transform/clip/cap pipeline stays the single authority on geometry. Addresses are normalised (strip 0x, lowercase) — hyprctl and socket2 disagree on the prefix. When rows carry no addr (geometry not yet re-synced), fx disables itself with a one-line warning instead of guessing.

The template in git ships FX_COUNT 0 and every branch compiles out — the same SHIPPED-AT-ZERO discipline the TUBE block carries, pinned by the same test. The watch splices this block from fx.glsl exactly the way tubes.glsl is spliced today, with the same must-define-a-count guard, and additionally treats a count above zero as zero when no watcher is alive — fx is runtime state that only a live watch can keep true.

💬 comment
The clock is forced, never latched
render() writes ANIMATED 1 whenever the spliced FX count is above zero, regardless of the stored animated flag — a flash needs a clock. But IGNITION never joins the MOTION tuple: turning the knob must not latch the steady-state clock on, or a transient nicety silently buys a permanent full-screen redraw. The clock exists exactly as long as an arc is in flight; the expiry swap takes it back out unless a motion knob holds it. preconditions() gets the same treatment: damage tracking follows (motion or fx active) or tube count, asserted before and after the swap as today, and re-asserted on configreloaded.
▼ Invariants that must hold
  • 💬 commentShipped at zero. Git carries FX_COUNT 0 and IGNITION 0.00; a clean install renders the exact pixels it renders today. test/run pins both, alongside the existing TUBE pin.
  • 💬 commentThe fx signature excludes baked offsets. FX_START changes on every bake by construction; hashing it rebuilds forever. Hash (addr, kind, mon, rect, t0) only.
  • 💬 commentIGNITION is not a motion knob. It never raises the stored animated flag. The clock rides the fx count through render(), transiently.
  • 💬 commentThe fx warp is self-contained. Always computed from FX_RECT/FX_CURV, never reused from the pixel’s live tube — a dying rect’s pixels may already belong to the sibling tube that reflowed into the space, and its local is the wrong frame.
  • 💬 commentThe knob scales the flash, never the ground. TD’s test asserts the tube face starts fully opaque — a half-transparent dark face would show the raw window through the flash, the one thing the effect exists to prevent. IGNITION dims the light; the darkness is all or nothing.
  • 💬 commentFlat, passthrough and unfocused-quiet surfaces never flash. Curvature zero is TD’s own gate and doubles as the no-double-ignition rule for Terminal Delight windows; passthrough pixels return before the fx loop could paint them; quiet monitors would freeze the arc mid-flight as a stranded artifact.
  • 💬 commentThe clock-reset behaviour is load-bearing and undocumented. probe-clock-reset is built first and re-run on every Hyprland upgrade. If it ever fails, the contingency is epoch-baked starts (measure Hyprland’s start time, bake absolute offsets) — uglier, drift-prone, and only reached for if the clean mechanism dies.
  • 💬 commentEvery teardown clears fx. flatten(), uninstall, and watch startup all write an empty FX block, so no stale flash can outlive the process that promised to finish it.

▼ Risks, each with its disproof
💬 comment
The clock does not actually reset on apply
Source-read, not yet screen-observed. Disproof: FX-0’s three captures. If red never returns to green on the re-apply, the finding falls, this spec pauses, and the epoch contingency gets its own review.
